Принцип вывода страниц пагинации и троеточия.

• totalPages = 2: выведется [1, 2].
• totalPages = 3: выведется [1, 2, 3].
• totalPages = 6 или 7: выведется полный ряд [1, 2, 3, 4, 5, 6, 7] без лишних троеточий.
• totalPages > 7 (например, 173): корректно включится скользящее окно с двумя троеточиями (1 2 3 4 ... 173, 1 ... 79 80 81 ... 173, 1 ... 169 170 171 172 173), без дублирования страниц на стыке с концом списка.
