Компонент QuestionSkeleton.jsx (Заглушка загрузки)
Роль в архитектуре: Презентационный компонент отображения ожидания. Имитирует блочную структуру статьи (заголовок, кнопки слайдера, абзацы короткого и полного ответов) с помощью CSS-анимации пульсации (@keyframes pulse). Служит временной заглушкой для сохранения стабильности Cumulative Layout Shift (CLS) левой колонки.
