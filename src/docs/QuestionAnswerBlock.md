Компонент QuestionAnswerBlock.jsx (Текстовые блоки)
Роль в архитектуре: Изолированный переиспользуемый UI-компонент (Dumb/Pure Component). Отвечает за безопасный рендер HTML-статей dangerouslySetInnerHTML, визуальное ограничение строк и независимое управление спойлерами. Используется на странице дважды: для shortAnswer и longAnswer.

📥 Входные параметры (Props):
• htmlContent (String, обязательный): Очищенная HTML-строка ответа для вывода.
• lineClamp (Number, обязательный): Лимит строк, выше которого текст будет схлопываться (например, 4 для краткого и 12 для полного ответа).
• isLongAnswer (Boolean, опционально): Флаг-маркер. Если true, компонент автоматически рендерит заголовок <h3>Полный разбор вопроса:</h3> и адаптирует текст на кнопках.

⚙️ Внутренняя логика и триада состояния:
1. const [isExpanded, setIsExpanded] = useState(false);
	• isExpanded (Boolean), Роль: Главный тумблер раскрытия. Переключает CSS-классы (.isExpanded / .isCollapsed) и текст на кнопке («Развернуть» / «Свернуть»).
2. const [showButton, setShowButton] = useState(false);
	• showButton (Boolean), Роль: Флаг переполнения. Если текст короткий и полностью помещается в лимит lineClamp, флаг остается false, скрывая кнопку и нижнюю тень, чтобы не захламлять интерфейс.
3. const textRef = useRef(null);
	• textRef (React.useRef), Роль: Прямой мост к физическому DOM-элементу в браузере. Позволяет хуку useEffect сопоставить полную высоту контента (scrollHeight) с видимой зажатой высотой (clientHeight). Если scrollHeight > clientHeight, код понимает, что текст обрезался, и включает showButton.

🔑 Механизм синхронизации через key:
Внутри QuestionPage каждый блок вызывается с уникальным ключом, привязанным к ID вопроса: key={short-${question.id}}. Благодаря этому при клике «Назад/Вперед» React не пытается обновить старый компонент, а полностью уничтожает его и создает новый с нуля. Это гарантирует моментальный сброс стейтов isExpanded и showButton в false, полностью исключая микро-рывки и баги отображения интерфейса.

ОПИСАНИЕ СОСТОЯНИЙ И ФУНКЦИЙ
1. const [isExpanded, setIsExpanded] = useState(false);
• Что это: Статус раскрытия текста (Да/Нет).
• Для чего нужно: Это состояние — главный переключатель тумблера. Оно определяет, в каком виде сейчас находится блок: свернут в аккуратную карточку или развернут во всю длину.
• Как это работает в коде:
	• Изначально оно равно false (текст свернут).
	• По клику на кнопку срабатывает функция setIsExpanded(prev => !prev), которая меняет значение на противоположное.
	• На основе isExpanded компонент решает, какой CSS-класс применить к блоку: ${isExpanded ? styles.isExpanded : styles.isCollapsed}. Если false — включается ограничение строк (line-clamp), если true — ограничение снимается.
	• Также от этого стейта зависит текст на самой кнопке: показывать пользователю надпись "Развернуть" или "Свернуть".


2. const [showButton, setShowButton] = useState(false);
• Что это: Флаг видимости кнопки «Развернуть» (Нужна кнопка / Не нужна).
• Для чего нужно: Защищает интерфейс от появления «бесполезных» кнопок. Если ответ автора состоит всего из одной строчки, ему нечего разворачивать. Кнопка под таким текстом будет выглядеть ошибкой.
• Как это работает в коде:
	• По умолчанию мы ставим false (кнопки нет).
	• Специальный хук useEffect (о нем ниже) измеряет текст в браузере. Если реальный текст оказался длиннее, чем выделенное ему место (4 или 12 строк), этот стейт переключается в true.
	• В JSX-разметке стоит условие: {showButton && <button>...</button>}. Кнопка физически отрендерится в DOM-дереве только тогда, когда текст действительно обрезался и нуждается в раскрытии.
	• PROD-бонус: По вашему запросу мы завязали на showButton еще и показ тени/градиента (styles.hasOverlay). Если showButton равен false (текст короткий) — тень тоже автоматически скрывается.

3. const textRef = useRef(null);
• Что это: Живой «мост» (ссылка) из кода React к реальному HTML-тегу в браузере.
• Для чего нужно: React работает с виртуальным деревом (Virtual DOM) и «не знает», сколько пикселей по высоте занимает текст на экране у конкретного пользователя (ведь у всех разные мониторы, масштабы и шрифты). Чтобы измерить физическую высоту блока в пикселях, нам нужно заглянуть в настоящий браузерный DOM. Для этого мы вешаем ref={textRef} на контейнер с текстом.
• Как это работает в коде:
	• Через textRef.current мы получаем доступ к стандартным свойствам браузерного тега: scrollHeight и clientHeight.
	• textRef.current.scrollHeight — это полная, реальная высота всего текста, если бы мы его вообще не ограничивали (даже если он занимает 3 экрана).
	• textRef.current.clientHeight — это видимая высота блока прямо сейчас на экране (то есть высота, зажатая рамками line-clamp в 4 или 12 строк).
	• Мы пишем математическое сравнение: const hasOverflow = scrollHeight > clientHeight;. Если полная высота больше видимой — значит, часть текста скрылась за экраном. Мы берем этот результат и передаем его в setShowButton(hasOverflow).

Как они работают в одной связке (Жизненный цикл):
1. Загрузка страницы: React берет текст вопроса и рендерит его. В этот момент isExpanded = false, showButton = false, а textRef только-только привязывается к тегу. Текст зажимается в CSS до 4 строк.
2. Шаг измерения (микросекунда после рендера): Срабатывает useEffect. Он берет textRef, смотрит в браузер и видит: «Ага, реальный текст (scrollHeight) равен 600px, а из-за ограничения строк видно только (clientHeight) 80px». 600 больше 80? Да!
3. Появление управления: Код вызывает setShowButton(true). Компонент перерисовывается: на экране плавно ложится тень-градиент и появляется кнопка "Развернуть краткий ответ".
4. Клик пользователя: Пользователь нажимает на кнопку. Вызывается setIsExpanded(true). Класс контейнера меняется на .isExpanded. Ограничение line-clamp в CSS отключается, max-height становится 5000px. Текст плавно раскрывается, тень исчезает, а на кнопке загорается надпись "Свернуть".
